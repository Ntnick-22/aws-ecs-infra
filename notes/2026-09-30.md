### Debugging lessons
| Symptom | Cause |
|---|---|
| `unknown directive "t"` → container exits | config error; nginx = PID 1, dies → container stops |
| `host not found in upstream "backend"` | container not on the network where `backend` exists |
| 502 + `Connection refused` | host reachable, wrong port (8080 vs 8000) |
| 502 / 503 / 504 | 502 upstream refused/broken · 503 unavailable / no healthy targets · 504 upstream never answered (on AWS: usually SGs) |

### Chunk 6 — images pushed to ECR (by hand)
```bash
REGISTRY=772297676546.dkr.ecr.eu-west-1.amazonaws.com
aws ecr get-login-password --region eu-west-1 | docker login --username AWS --password-stdin $REGISTRY
TAG=$(git rev-parse --short HEAD)          # commit first → tag = exact code
docker build --provenance=false -t $REGISTRY/myecs-backend:$TAG .
docker push $REGISTRY/myecs-backend:$TAG
```
- Registry = `<account>.dkr.ecr.<region>.amazonaws.com`; no registry in the name → Docker Hub
- ECR login: IAM credentials → 12h token → `docker login` (username is always `AWS`)
- Tag = movable label; digest (`sha256:…`) = content fingerprint. IMMUTABLE locks tag → digest
- Without `--provenance=false`, BuildKit pushes an image index + image + attestation (3 ECR rows)
- Shell variable (`X=1`, expanded by bash) vs environment variable (`export X=1`, visible to child programs)
